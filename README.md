⚙️ How to Use

Open portfolio.html from the Portfolio folder

## 🚀 Features

* 📄 Clean multi-section layout (Hero, Projects, Skills, About, Contact)
* 📱 Fully responsive design (mobile, tablet, desktop)
* 🌙 Modern dark-themed UI with accent colors
* 📐 Layout built with CSS Grid & Flexbox
* 🎯 Interactive project cards with previews
* 📊 Visual skill representation with progress bars
* 🧭 Smooth scrolling navigation
* 📖 Timeline section showing my learning journey
